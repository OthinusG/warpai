01

纯净原生，零遥测无登录墙。 →

Warpai 不是 Electron 网页打包，更不是云端托管。它基于 100% 纯 Rust 构建，支持 Metal 与 DirectX GPU 原生硬件加速。我们彻底剥离了全部 51+ 个云端 AI 文件、Sentry 遥测与强制登录限制。你的终端、密钥与代码完全属于你自己。

warpai-corelocal-first
0 次外部遥测请求 · 0 处强制云端校验 · 100% 隐私安全
02

无需逐个翻找停滞的终端。 →

Warpai 内置 VT100 屏幕观察器，直接在内存中解析原始终端 ANSI 流，精准识别每个 Agent 的状态：Working（执行中）、WaitingApproval（等待审批）与 Idle（空闲就绪）。当 Agent 需要授权时，标签页与侧边栏状态指示即时切换为 WaitingApproval，并触发系统桌面通知，无需逐屏翻找排查。

feat/agent-buswaiting approval
warpai (main)working
infra/remoteidle
03

守护式 PTY 交互交付。 →

普通终端在 Agent 持续输出或重绘时容易吞掉键盘输入或导致指令错乱。Warpai 实行守护式 PTY 交付，确保只有在底层 CLI 处于真正且稳定的提示符状态时才投递字符，彻底杜绝丢键与并发撞车。

04

开箱即用，原生适配已有工具。 →

Claude Code、Codex、Gemini、Antigravity、Cursor、Trae、Pi、Goose、Grok、Amp、Auggie、Droid 等全面支持。Warpai 不使用私有 API 封装篡改它们，而是通过精准的 VT100 描述清单与原生分屏，直接赋予它们工业级的运行底座。

05

统一连接所有设备：原生支持 macOS、Windows WSL 与云端 Linux。 →

全面覆盖 MacBook、Windows 原生桌面、Windows WSL/WSL2 子系统，以及云端 Linux GPU 服务器。通过 SSH 无缝接入 Warpai 远程伴侣，本地 WSL 发行版与远端 GPU 工作区一屏聚合，支持内置 SFTP 文件互传，操作无任何感知延迟。

$ warpai companion attach workbox-gpu
本地桌面 / Windows WSL2已就绪
workbox-gpu (SSH)已连接
06

专为泛行业赋能：Worktree 编码与 Project 全向协同双模式。 →

主流多 Agent 软件往往局限于 Git Worktree 单一代码开发模式。Warpai 针对 Git 代码仓库提供严谨的 Worktree 并发模式：除协调者统筹外，每个 Worktree 可以并行开发不同的功能特性，物理分支隔离互不干扰。在此之上，Warpai 倾力扶持非 Coding 场景，重磅推出 Project 模式：在同一项目空间内，所有 Agent 彻底打破单一上下级限制，均可作为指挥官（Commander）或工人（Worker），互相通信、提问应答与流转任务！全面赋能：科研论文写作与审稿、工业级视觉与多媒体设计、量化投研与金融分析、专利交底挖掘与法务合规、自媒体脚本与矩阵运营、商业尽调与战略情报等 6+ 大泛行业场景。
