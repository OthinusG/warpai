You never hunt for the stuck one. →

Warpai's built-in VT100 screen observer analyzes raw terminal output in memory, identifying every agent's state: Working, WaitingApproval, or Idle. When an agent stops and needs permission, the status tab badge immediately updates to WaitingApproval and triggers desktop notifications—no more pane-by-pane searching.

03

Guarded PTY delivery. →

Ordinary terminals drop inputs or clobber commands when an agent CLI is redrawing or busy thinking. Warpai gates PTY delivery so instructions only land when the agent CLI is at a true input prompt, preventing garbled keystrokes and unintended execution.
