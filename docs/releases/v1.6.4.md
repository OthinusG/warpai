# Warpai 1.6.4

Warpai 1.6.4 fixes Agent readiness, queued task delivery, language restart and
Windows WSL Companion installation. Companion is updated to 5.1.0; SSH protocol
major remains 1 and Agent Bus protocol major remains 2.

## Agent readiness and task delivery

- Idle Codex sessions no longer appear to be working immediately after launch.
  Startup acknowledgements and prompt edits preserve readiness for queued work.
  Agent status stays consistent between the sidebar and collaboration panel.
- Unsubmitted input in the Agent's native terminal no longer blocks queued tasks.
  Warpai clears that native input at the idle prompt before delivering the task.
  Draft text and attachments in Warpai's own input box remain available.
- Permission requests, cancellation and active work still prevent automatic
  submission. Task delivery retains native run and input guards.

## Usage display

- Antigravity displays two usage pools: Claude/GPT and Gemini. Each displays
  either its five-hour or weekly reading according to the existing account setting.
- Other providers with five-hour readings use the same exclusive window choice.
  Providers without that window retain their reported quota or balance.

## Restart and Windows Companion

- Restart after changing the interface language now reopens the application.
- WSL Companion setup and recovery no longer fail during installed-Agent discovery
  because of a nested asynchronous runtime. Installation acceptance now includes
  a nonempty Agent scan.
- Background Agent configuration and Companion probes suppress visible Windows
  command windows. Interactive terminal processes retain their normal behavior.
- Windows bundles the updated WSL Companion 5.1.0. Remote installers also contain
  Companion 5.1.0. Update the desktop and Companion from this release.

## Installers

- macOS Apple silicon: `Warpai-1.6.4-macos-arm64.dmg`.
- Windows x64: `WarpaiSetup-1.6.4-windows-x64.exe`.
- Remote Linux x64: `WarpaiCompanion-5.1.0-linux-x64.run`.
- Remote macOS Apple silicon: `WarpaiCompanion-5.1.0-macos-arm64.dmg`.
- Remote Windows x64: `WarpaiCompanion-5.1.0-windows-x64-setup.exe`.

Provider CLI requirements and authentication remain specific to each environment.
This release adds no telemetry, bundled cloud AI or Warpai account requirement.
