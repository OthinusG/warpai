# Warpai 1.7.2

Warpai 1.7.2 adds native communication and plan usage monitoring for Qoder and
QoderCN CLI sessions. Qoder and QoderCN remain separate agents; `qoder-cn` is
available as an alias for QoderCN.

## Qoder agents

- Connect QoderCN sessions launched with `qoder-cn` to Warpai's native Agent
  communication and monitoring system.
- Show the current Qoder or QoderCN CLI login's plan and organization usage
  without requiring a separately installed SDK.
- Check usage automatically no more than once every five minutes per account;
  manual refresh remains available at any time.

The release retains the Linux desktop packages introduced in 1.7.1 and the
existing Companion 5.4.0 protocol.
