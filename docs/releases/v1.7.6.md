# Warpai 1.7.6

Warpai 1.7.6 combines the unpublished 1.7.2 Qoder improvements with a shared
SSH workspace selection repair for macOS, Windows, and Linux desktops.

## SSH workspaces

- Reuse the terminal's confirmed OpenSSH control connection even when the
  original SSH launch arguments are unavailable, allowing the remote file
  explorer and Agent collaboration to select that session.
- Accept the native shell's `~/.ssh/` control socket paths consistently for
  Companion and SFTP connections, with home expansion owned by OpenSSH.
- Preserve native Windows SSH authentication and WSL account isolation,
  including SSH connections established from inside WSL.

- Add an independent SSH Remote master switch and logged-in account selector
  under Settings > Features > Agent communication. Select remote Agents to
  install or remove their native MCP integration without manual launch wrappers.
- Configure each remote account through its own Companion; preserve unrelated
  vendor settings and existing MCP integrations. SSH terminal IO remains usable
  while SSH Remote features are disabled.

- Select native PowerShell bootstrap for Windows SSH targets before sending
  shell commands. Load the full integration through an owned remote temporary
  script, retaining ordinary SSH access independently of Companion settings.
- Use the remote operating system for PowerShell path separators and executable
  completion aliases, including macOS clients connected to Windows.

## SSH Agent readiness

- Forward verified native SSH screen activity to Companion so panel and MCP
  queries recognize initial readiness before the first conversation.
- Preserve the native tab status, input guards, run identity and separate
  SSH/WSL master policies.
- Wake idle native SSH Agents for pending collaboration work through the same
  guarded delivery protocol as WSL, preserving drafts and approval dialogs and
  validating the current run again before submission.

## Qoder agents

- Connect QoderCN sessions launched with `qoder-cn` to native Agent
  communication and monitoring. Qoder and QoderCN remain separate agents.
- Show the current Qoder or QoderCN CLI login's plan and organization usage
  without requiring a separately installed SDK.
- Check usage automatically no more than once every five minutes per account;
  manual refresh remains available at any time.

The release retains Linux x64 and ARM64 desktop packages and Companion 5.5.0
with SSH protocol major 1. SSH native MCP setup requires Companion 5.5.0;
the connection-only repair remains compatible with Companion 5.4.0.
