# Warpai 1.7.1

Warpai 1.7.1 adds native Linux desktop packages alongside dynamic task
supervision and safe application restart after language changes. The updated
Companion is version 5.4.0; SSH protocol major remains 1.

## Linux desktop

- Add native Linux desktop packages for x86_64 and ARM64: `.deb`, `.rpm`, Arch
  `.pkg.tar.zst`, and AppImage. Linux builds target glibc 2.31 or newer.
- Include systemd-logind keep-awake inhibition and safe application restart
  after language changes.
- Preserve the native Agent communication bridge, desktop identity, licensing
  notices, provenance manifests, and package checksums.

## Agent coordination

- Dispatch work to supervising Agents at any time; newly assigned tasks enter
  the supervision list and completed tasks leave it.
- Keep busy Agents' incoming tasks and messages queued in arrival order without
  interrupting in-flight work.
- Keep Companion MCP guidance active across multiple concurrent tasks.

See the repository documentation for installation requirements and supported
platform details.
