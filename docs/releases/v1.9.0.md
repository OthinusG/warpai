# Warpai 1.9.0

## Continuous supervision and recovery

- Needs attention groups questions, review, input/permission waits, dependencies,
  overdue work, unreachable Agents, uncertain execution and overtaken follow-ups.
  One task can have several pending actions, with whole-filter totals and paging.
- Returning supervisors rebuild delegated tasks, unanswered requests, unhandled
  results and addressed questions from durable facts. The active Worktree
  Coordinator can recover inherited task duties without changing task ownership.
- Task-linked follow-ups retain their original revision. Overtaken instructions
  stay readable, are skipped by automatic delivery and can be explicitly ended.
  Read acknowledgement is separate from closure; ended instructions reject late
  results and retire their associated questions.
- Browse all unresolved overtaken follow-ups independently of compact previews.
  Archived work stays recoverable while unresolved facts still need handling.

## Traceable continuation and terminal reliability

- Handoff inputs surface source changes and execution uncertainty while retaining
  exact immutable pins. Briefs preserve task/attempt provenance, decisions,
  unresolved issues and next steps without importing terminal transcripts.
- Shared response budgets keep paged collaboration data within local and remote
  transport limits, including multibyte text.
- Cancelled and archived tasks stay out of the default task list; history retains
  their records. Archive accepts an empty reason.
- Sidebar resize hit areas follow the visible edges, with stable drag position
  and cursor behavior. Terminal input remains aligned with the side panels.
- Antigravity usage queries use the system proxy route for the usage child;
  macOS test installer creation retries temporary busy-volume detach failures.

## Packages

Desktop: macOS Apple Silicon, Windows x64, Linux x64/ARM64 (glibc >= 2.31).
Companion 6.1.0: Linux x64, macOS Apple Silicon and Windows x64. Update Companion
for SSH/WSL to use the matching supervision and follow-up features; ordinary local
terminals require no Companion installation. SSH major 1 and Agent Bus major 2
remain unchanged. macOS packages are ad-hoc signed; Windows installers are unsigned.

## 持续督办与恢复

- Needs attention 汇集待回答、待评审、输入或权限等待、依赖、超期、Agent 不可达、
  执行不确定性和过时追问。同一任务可有多项待办，分页保留整个筛选范围的总数。
- 返回的监督者可从持久事实重建委派任务、未获答复的请求、未处理结果及发给自己的
  问题。当前 Worktree Coordinator 可接续历史任务职责，无需改变任务所有者。
- 任务关联追问保留发送时的版本。旧指令保留可查，跳过自动投递，并可显式结束。
  已读与解决分开；结束后的指令拒绝迟到结果，相关问题一并结束。
- 未结束的过时追问可独立完整分页，不受摘要预览数量限制。归档任务仍有未决事实时，
  继续保留在恢复范围中。

## 可追溯接续与终端可靠性

- 交接输入提示源变化和执行不确定性，同时保留准确的不可变引用。简报关联任务与
  执行来源、决策、未解决问题和后续步骤，无需导入终端记录。
- 共享响应预算约束协作分页数据，兼顾本地、远端与多字节文本。
- 默认任务列表隐藏已取消和归档任务，历史记录保留；归档原因可留空。
- 侧栏拖拽热区对齐可见边缘，改善拖动位置和光标稳定性；终端输入与侧栏保持对齐。
- Antigravity 用量查询为子进程应用系统代理路由；macOS 测试安装包创建支持临时
  卷占用导致的卸载重试。

## 安装包

桌面端支持 macOS Apple Silicon、Windows x64、Linux x64/ARM64（glibc >= 2.31）。
Companion 6.1.0 支持 Linux x64、macOS Apple Silicon 和 Windows x64。SSH/WSL
请更新配套 Companion 以使用对应督办与追问能力；普通本地终端无需安装 Companion。
SSH 协议主版本仍为 1，Agent Bus 主版本仍为 2。macOS 使用 ad-hoc 签名，
Windows 安装包未签名。
