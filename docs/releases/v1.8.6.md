# Warpai 1.8.6

## **Companion compatibility: overwrite-install Companion 6.0.0**

**Companion versions used before and from Warpai 1.8.6 are not interchangeable.
Warpai 1.8.6 requires Companion 6.0.0. Overwrite-install the matching new
Companion on every remote host under the same SSH account, then reconnect.
Update dedicated local WSL installations through Settings > Features > Agent
communication > WSL. Keep older desktops paired with their matching older
Companion; do not downgrade an updated data store.**

## Task handoff briefs

- Submitting a tracked task saves an immutable handoff brief. Failure and confirmed
  cancellation retain partial/stopped briefs; explicit progress checkpoints can
  save decisions, unresolved issues and ordered next steps.
- Browse exact versions from task detail/history and load full content on demand.
  Read current source status and review separately from the immutable snapshot.
- Pin a brief to a subsequent task or explicitly share that exact version. Sharing
  grants only the selected version, not source-task, filesystem or execution authority.
- Protected handoff sources remain available while live tasks or messages refer
  to them. Normal task-start, review and recovery checks still apply.

## Terminal and collaboration refinements

- Vertical tabs use inset columns, aligned toolbars and terminal surfaces, and
  rounded history-group boundaries. Internal history joins remain square;
  offscreen boundaries do not gain artificial corners.
- Local icon submenus no longer show the overlapping tooltip corner.
- History navigation uses consistent native buttons. Archived tasks visibly retain
  their outcome; repeated archival is a no-op. Confirmed Delete targets one task
  with version, unread-message, certainty and reference guards.
- Known CLI Agent executable recognition ignores ASCII case while preserving
  arguments and native shell alias/function semantics.
- Explicit delegated work uses task assignment; ordinary peer messages remain
  messages and do not create supervised tasks.

Desktop: macOS Apple Silicon, Windows x64, Linux x64/ARM64 (glibc >= 2.31).
Companion: Linux x64, macOS Apple Silicon and Windows x64. macOS packages are
ad-hoc signed; Windows installers are unsigned. SSH protocol major 1 and Agent
Bus major 2 remain unchanged; use the matching release packages.

## **Companion 兼容性：必须覆盖安装 Companion 6.0.0**

**Warpai 1.8.6 前后的 Companion 不通用。Warpai 1.8.6 必须配套
Companion 6.0.0；请在每台远程主机上，以原 SSH 账号覆盖安装新版 Companion，
然后重新连接。本地 WSL 请通过 Settings > Features > Agent communication > WSL
更新专用组件。旧版桌面端继续配套旧版 Companion，不支持降级已更新的数据存储。**

### 任务交接简报（handoff）

- 提交受跟踪任务时保存不可变交接简报；任务失败和确认取消时保留部分成果或停止点。
  显式进度检查点可记录决策、未解决问题与有序后续步骤。
- 在任务详情和历史中浏览具体版本，按需加载内容；当前源任务状态与评审结果独立显示。
- 后续任务可固定引用某份简报，也可显式共享指定版本。共享不会授予源任务、文件系统
  或执行权限，仍须遵守正常的任务启动、评审和恢复流程。
- 活跃任务或消息仍引用交接简报时，源记录受保留保护。

### 终端与协作体验

- 纵向标签采用内缩面板、对齐工具栏和终端区域；历史块只在整组外沿显示圆角，
  内部连接处保持直角，真实超出视口的边界不生成圆角。
- 图标二级菜单移除重叠提示产生的灰色角，历史导航统一使用原生按钮样式。
- 归档保留任务结果并显示归档标记，重复归档不再增加版本号；Delete 经确认后仅删除
  指定任务，并保留版本、未读消息、执行确定性与引用保护。
- 已知 CLI Agent 命令识别忽略 ASCII 大小写，参数与 Shell 别名、函数规则保持原样。
- 委派任务使用任务分配接口；普通对等消息不会自动创建受监督任务。

桌面端支持 macOS Apple Silicon、Windows x64、Linux x64/ARM64（glibc >= 2.31）；
Companion 支持 Linux x64、macOS Apple Silicon 和 Windows x64。macOS 使用 ad-hoc
签名，Windows 安装包未签名。SSH 协议主版本仍为 1，Agent Bus 主版本仍为 2，
请使用同一发布版本的配套安装包。
