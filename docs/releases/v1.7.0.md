# Warpai 1.7.0

Warpai 1.7.0 adds dynamic task supervision and safe application restart after
language changes. The updated Companion is version 5.4.0; SSH protocol major
remains 1.

## Desktop

- Safely restart the application after language changes.
- Retain the native Agent communication bridge, resources, desktop identity,
  licensing notices, provenance manifests, and package checksums.

## Agent coordination

- Let the supervising Agent dispatch new work at any time. Newly assigned tasks
  enter its supervision list, and completed tasks leave the list.
- Keep busy Agents' incoming tasks and messages queued in arrival order without
  interrupting in-flight work.
- Update Companion MCP guidance to keep dispatch and supervision active across
  multiple concurrent tasks.

See the repository documentation for installation requirements and supported
platform details. The Linux Companion package supports remote Linux hosts.
