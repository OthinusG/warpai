# Warpai 1.8.1

## Independent pane icons

- Choose a bundled icon for each pane, or select a local SVG/PNG file from
  `~/.config/warpai/icon`. Local images retain their colors and transparency.
- Panes keep independent selections. Saving a tab with **Save as new config**
  writes each icon to its corresponding `[[panes]]` TOML entry; reopening that
  config restores the selections. Session restoration and pane transfers also
  preserve them.
- Reset an individual pane's icon without changing its siblings. Missing or
  invalid local images fall back to the native icon.
- Native SSH sessions use a circular SSH badge. Active Agent branding and status
  take priority over a selected icon. Horizontal tabs retain their standard icons.
- The picker supports English, Simplified Chinese and Traditional Chinese.

## Provider usage

- Usage requests support macOS automatic proxy configuration (PAC).
- Qoder and QoderCN usage queries use the local CLI daemon protocol, with a
  fallback for older CLI versions, without submitting a model prompt.

Companion remains 5.5.0; SSH protocol major 1 and Agent Bus major 2 are unchanged.

Desktop installers support macOS Apple Silicon, Windows x64, and Linux x64/ARM64.
Linux packages require glibc 2.31 or later. macOS builds are ad-hoc signed;
Windows installers are unsigned.
