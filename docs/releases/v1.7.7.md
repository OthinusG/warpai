# Warpai 1.7.7

Warpai 1.7.7 corrects shell initialization visibility in local and SSH Zsh
sessions. Bootstrap input is now hidden while it is read, and normal terminal
settings are restored before the shell evaluates the bootstrap and user startup
files.

This patch release carries forward the unreleased 1.7.6 changes:

- Repair shared SSH workspace selection across macOS, Windows, and Linux.
- Add the SSH Remote master switch and per-account native MCP setup.
- Support native PowerShell startup for SSH connections to Windows.
- Report initial SSH Agent readiness and support guarded collaboration wakeups.
- Connect QoderCN sessions to Agent communication and show Qoder usage.
- Retain Linux x64 and ARM64 desktop packages and Companion 5.5.0.

SSH native MCP setup requires Companion 5.5.0. SSH connection repairs remain
compatible with Companion 5.4.0.
