# Warpai 1.7.8

Warpai 1.7.8 restores WSL sessions on Windows and SSH connections to remote
shells. Real-machine acceptance covered SSH connections to Linux, macOS and
Windows hosts as well as local WSL.

- Shorten the Windows PowerShell SSH bootstrap seed so the encoded input stays
  below the console input limit, eliminating the hang at "Starting shell..."
  when opening a Warpai shell on a Windows host.
- Restore WSL auto-warpify when entering `wsl` from a Windows terminal by
  preserving the pending configuration epoch during unrelated SSH updates.
- Keep Zsh bootstrap injection in raw mode so initialization input stays hidden
  before the user's prompt appears.
- Add regression coverage for the minified Windows seed, the raw-mode subshell
  initialization and the WSL polling epoch.

SSH to Linux, macOS, Windows and local WSL was verified on real machines.
Companion remains 5.5.0; SSH protocol major 1 and Agent Bus major 2 are
unchanged. Desktop packages are provided for macOS, Windows, Linux x64 and
Linux ARM64.
