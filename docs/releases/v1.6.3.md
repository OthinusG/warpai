# Warpai 1.6.3

Warpai 1.6.3 improves Agent delivery, project supervision and native remote
workspaces. Companion is updated to 5.0.0; SSH protocol major remains 1 and Agent
Bus protocol major remains 2. Update the desktop and Companion from this release.

## Agent collaboration

- Use **Send to Agent** for ordinary messages or enable **Track as task** for
  tracked assignments. Replies remain associated with the original request/task
  and return to the immediate issuer. Busy Agents retain results in arrival order.
- Project participants share observations, progress, questions, permission waits,
  timeout/uncertainty and supervision decisions. Retried requests preserve their
  identity. Timeouts do not automatically rerun work; Agents decide retry,
  reassignment and acceptance against the current task revision.
- Worktree collaboration recognizes the main checkout and manually started CLI
  Agents. Coordinator selection preserves the existing native run. Worktree
  removal checks terminals in open tabs and retains Git's checkout protections.

## Windows, SSH and WSL

- Confirmed SSH/WSL terminal context governs collaboration and File Explorer
  availability independently of local communication. Disabled communication or
  unavailable Companion no longer causes repeated background launches.
- Interactive WSL launches enter shell integration by default while respecting
  opt-outs. Guest accounts and Agents remain scoped to the distribution/account;
  separate terminals can work independently in the same guest project.
- Companion installation/removal displays progress and retains failure details.
  Trusted bundled recovery supports damaged or missing WSL installations while
  preserving SSH, projects, shell profiles and unrelated files.
- Missing local Git has an explicit localized explanation. Local Git features
  require system Git; Companion's private Git supplies remote infrastructure and
  does not replace Git in an interactive shell. See
  [feature dependencies](../FEATURE-DEPENDENCIES.md).

## Interface and usage

- Offer restart after changing interface language. Complete Simplified and
  Traditional Chinese display strings and improve native Windows glyph fallback.
- Keep Data usage at the panel bottom with its own bounded scrolling. API entry
  and browser sign-in share one flow with a Back action. Separate Antigravity's
  Gemini and third-party pools; configure five-hour usage detection per account.
- Align expanded History controls and indent worktree details beneath headings.

## Installers

- macOS Apple silicon: `Warpai-1.6.3-macos-arm64.dmg`.
- Windows x64: `WarpaiSetup-1.6.3-windows-x64.exe`.
- Remote Linux x64: `WarpaiCompanion-5.0.0-linux-x64.run`.
- Remote macOS Apple silicon: `WarpaiCompanion-5.0.0-macos-arm64.dmg`.
- Remote Windows x64: `WarpaiCompanion-5.0.0-windows-x64-setup.exe`.

Retain provider CLI requirements and authentication in each selected environment.
This release adds no telemetry, bundled cloud AI or Warpai account requirement.
