# Warpai 1.8.0

## Vertical tab icons

- Choose a bundled icon from a tab's context menu, or select a local SVG/PNG
  from `~/.config/warpai/icon`. Local icons retain their colors and transparency.
- Icon selections persist per tab across restarts and moves between windows.
  Missing or invalid local icons fall back to the terminal's default icon.
- Native SSH sessions display a circular SSH badge. Agent branding and status
  take priority over a selected icon; horizontal tabs retain their existing icons.
- Icon selection and reset return focus to the terminal. The picker supports
  English, Simplified Chinese and Traditional Chinese.

## Provider usage

- Usage requests honor macOS automatic proxy configuration (PAC).
- Qoder and QoderCN usage queries support the daemon SDK protocol, with a
  fallback for older CLI versions.

Companion remains 5.5.0; SSH protocol major 1 and Agent Bus major 2 are unchanged.

Desktop installers are available for macOS Apple Silicon, Windows x64, and Linux
x64/ARM64. Linux packages require glibc 2.31 or later. macOS builds are ad-hoc
signed; Windows installers are unsigned.
