# Warpai 1.7.8.1

Warpai 1.7.8.1 fixes a collision between local Agent MCP setup and SSH MCP
setup. Each scope now uses a distinct MCP server name:

- Local Agent: `warpai-local-com`
- SSH Agent: `warpai-ssh-com`
- Direct WSL Agent: `warpai-wsl-com`

Configuration injection and cleanup preserve unrelated MCP servers and remove
only recognized legacy Warpai registrations. WSL remains a server-side
Companion scope and does not inject MCP into the local host configuration.

The MCP scope change passed the macOS, Windows and Linux cloud acceptance suites,
including local settings and Codex startup, SSH setup, configuration migration,
Companion protocol tests, and WSL integration checks.

Companion remains 5.5.0; SSH protocol major 1 and Agent Bus major 2 are unchanged.
