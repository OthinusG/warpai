# Warpai 1.7.8.2

Warpai 1.7.8.2 is a bugfix release for native Agent MCP installation after the
1.7.8.1 server-name change. Existing QoderCN settings now migrate their saved
install, lookup, and cleanup commands to the current server name, so setup and
uninstall can find the same MCP entry. Existing user MCP entries and Agent
activation preferences are preserved.

Companion remains 5.5.0; SSH protocol major 1 and Agent Bus major 2 are unchanged.
