# Warpai 1.7.8.2

Warpai 1.7.8.2 is a bugfix release for Agent MCP installation after the 1.7.8.1
server-name change. Saved local, SSH, and WSL records now migrate their install,
lookup, and cleanup commands to the current scope name. Inactive cleanup records
can be selected again from Settings. Existing user MCP entries and activation
choices are preserved.

Companion remains 5.5.0; SSH protocol major 1 and Agent Bus major 2 are unchanged.
