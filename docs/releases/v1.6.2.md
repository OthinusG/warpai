# Warpai 1.6.2

Warpai 1.6.2 adds Simplified and Traditional Chinese interface languages, moves
desktop configuration to `~/.config/warpai`, and updates fresh-install and Reset
defaults. Companion remains 4.0.0 and protocol major remains 1.

## Changes from 1.6.0

- Choose English, 简体中文 or 繁體中文 in Settings > Appearance > Language.
  Restart Warpai to apply the selection throughout the interface, including
  native menus, settings, collaboration, editors and accessibility labels.
  Commands, terminal output, file contents, paths and user-provided names retain
  their original text.
- Desktop data and preferences use `~/.config/warpai`. Existing data from
  `~/.config/.warpai` is imported without overwriting new-root values. Profiles,
  themes, keybindings, sessions and collaboration history are preserved; source
  files remain available for recovery. SQLite migration includes committed WAL
  changes. Reset preferences are not reimported on later startups.
- Fresh-install and Reset defaults reflect the owner's public interface and
  terminal preferences, including the bundled Claude Warm Light theme. The dark
  default uses built-in Dark. Accounts, credentials, project paths, history and
  MCP server definitions are excluded from defaults.
- Existing local, SSH and Windows WSL workspace features are retained. Remote
  Companion installation paths and the 4.0.0 runtime contract are unchanged.

## Downloads

- macOS 11.0 or newer, Apple silicon: `Warpai-1.6.2-macos-arm64.dmg`.
- Windows x64: `WarpaiSetup-1.6.2-windows-x64.exe`.
- Remote Linux x64: `WarpaiCompanion-4.0.0-linux-x64.run`.
- Remote macOS Apple silicon: `WarpaiCompanion-4.0.0-macos-arm64.dmg`.
- Remote Windows x64: `WarpaiCompanion-4.0.0-windows-x64-setup.exe`.

The Windows desktop installer includes the WSL guest payload. SHA-256 lists
cover all five public installers. macOS uses ad-hoc signing; Windows installers
are unsigned and may require first-launch approval.

## Verification

Release requires source-matched macOS and Windows acceptance, migration/defaults
tests, translation checks and native screenshots in all three languages. The
[1.6.2 technical specification](https://github.com/OthinusG/warpai/blob/v1.6.2/specs/1.6.2/TECH.md)
records the acceptance gates. Tagged installer, source, version and runtime checks
also run during packaging. Acceptance uses owned fixtures without personal
credentials or live vendor model requests.
