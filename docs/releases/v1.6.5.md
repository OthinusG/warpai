# Warpai 1.6.5

Warpai 1.6.5 repairs native Agent status and MCP participation, reduces input
latency, and makes participant names copyable. Companion is updated to 5.3.0;
SSH protocol major remains 1 and Agent Bus protocol major remains 2.

## Agent status and communication

- Adopt Herdr screen rules across named Agents and aliases, including Antigravity
  and Qoder/QoderCN, with supplementary rules for DeepSeek Harness, Auggie, Goose
  and TRAE. Known clients with settled screens and no matching rule default to Idle.
- Waiting for approval or an answer remains connected through MCP. New native
  instructions stay queued until the prompt is eligible for guarded delivery.
  Returning to Idle never acknowledges a message or completes a task.
- WSL admission follows verified foreground process ancestry, including nested MCP
  plugin hosts. A replaced native run can be rediscovered without applying stale
  screen evidence; stale delivery commands remain rejected.
- Companion-owned SSH Agent terminals use the same state rules and existing MCP
  adapters, retaining original run, account, input, task and cancellation guards.

## Responsiveness and panel

- Reuse unchanged terminal evidence instead of repeatedly copying native screens.
  Classification, panel projection and local form queries run in background workers.
- Keep Git branch queries outside the Broker lock shared with native input/output.
  Revalidate admitted worktrees from their native metadata without launching Git
  for repeated MCP authorization checks.
- Reuse empty queue projections until communication changes, and stop unchanged
  input guards or read-only queries from waking all waiting MCP clients.
- Click a participant name in the Project or Worktree panel to copy its full name
  to the native clipboard. Preserve drafts and existing selection controls.
- Remove yellow unread/pending-work dots from the left vertical tabs.

## Installers

- macOS Apple silicon: `Warpai-1.6.5-macos-arm64.dmg`.
- Windows x64: `WarpaiSetup-1.6.5-windows-x64.exe`.
- Remote Linux x64: `WarpaiCompanion-5.3.0-linux-x64.run`.
- Remote macOS Apple silicon: `WarpaiCompanion-5.3.0-macos-arm64.dmg`.
- Remote Windows x64: `WarpaiCompanion-5.3.0-windows-x64-setup.exe`.

Install the desktop and matching Companion from this release. Vendor CLI versions,
runtimes and authentication remain environment-owned; shared background daemons
require verified per-session MCP binding. This release adds no telemetry or cloud AI.
