# Warpai Official Website

This repository contains the source code for the official website and documentation of **Warpai**, hosted on GitHub Pages (`gh-pages` branch).

## Overview

- **Production URL**: https://othinusg.github.io/warpai/
- **Framework**: Jekyll (GitHub Pages compatible)
- **Languages**: English (default root) and Simplified Chinese (`zh/`)

## Structure

- `_config.yml`: Jekyll configuration and site metadata.
- `_data/`: Data dictionaries (e.g. `strings.yml` for i18n text).
- `_includes/`: Shared HTML components (`header.html`, `footer.html`).
- `_layouts/`: Page layouts (`default.html`, `docs.html`).
- `assets/`: Static assets (CSS, fonts, images, JS).
- `docs/`: English documentation pages (Markdown).
- `zh/`: Chinese homepage and documentation pages.
- `index.html`: English landing page.
